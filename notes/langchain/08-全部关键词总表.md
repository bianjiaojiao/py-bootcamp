| --- | --- |
| `get_llm()` | 造模型对象（读 key + 连 DeepSeek） |

## A2 定规矩（L2）

| 词 | 一句话 |
| --- | --- |

## A5 工具申请（L5）

| `tool_calls` | 模型的申请单（列表套字典：name / args / id） |

## A6 工具执行（L6）

| 词 | 一句话 |

| 工具 `.invoke({...})` | 执行工具，参数用字典 |

## A7 图（L7）

| 词 | 一句话 |
| --- | --- |
| `StateGraph(State)` | 建图 |

| `START` / `END` | 起点 / 终点 |

| 词 | 一句话 |

## A12 人工确认（L12）

# Part B · RAG（R1~R8，21 词）

> R1~R3 已学；R4~R8 还没学，先混个脸熟。

## B1 为什么需要 RAG（R1）

| 词 | 一句话 | 状态 |
| --- | --- | --- |
| RAG | **R**etrieval-**A**ugmented **G**eneration，检索增强生成：先找资料，再回答 | ✅ 已学 |
| 幻觉（hallucination） | 模型编一个看起来对的假答案 | ✅ 已学 |

## B2 切块（R2）

| 词 | 一句话 | 状态 |
| --- | --- | --- |
| chunk（块） | 把长文本切成的小段 | ✅ 已学 |
| `RecursiveCharacterTextSplitter` | 递归切块器：段落→换行→句子→字符，逐级降级 | ✅ 已学 |
| `chunk_size` | 每块最多多少字符 | ✅ 已学 |
| `chunk_overlap` | 相邻块重叠多少字符 | ✅ 已学 |
| `.split_text(text)` | 切分，返回块列表 | ✅ 已学 |

## B3 文字变数字（R3）

| 词 | 一句话 | 状态 |
| --- | --- | --- |
| embedding | 把文字变成一串数字（向量） | ✅ 已学 |
| 向量（vector） | 那串数字，512 个 | ✅ 已学 |
| 维度（dimension） | 向量的长度（本课 512，固定） | ✅ 已学 |
| `TextEmbedding("模型名")` | 加载文字→数字的模型 | ✅ 已学 |
| `.embed([文本, ...])` | 批量转换，返回向量列表 | ✅ 已学 |

## B4 算"像不像"（R4）

| 词 | 一句话 | 状态 |
| --- | --- | --- |
| 余弦相似度（cosine similarity） | 0~1 的数字，越大越像 | ⬜ 将学 |
| 点积（dot product） | 两个向量对应位相乘再求和 | ⬜ 将学 |
| 模长（norm） | 向量自己的长度 | ⬜ 将学 |

## B5 存起来 + 找出来（R5）

| 词 | 一句话 | 状态 |
| --- | --- | --- |
| 向量库（vector store） | 存"文本 + 向量"的地方 | ⬜ 将学 |
| 检索（retrieval） | 拿问题向量去库里找最像的几块 | ⬜ 将学 |
| `top_k` | 取最像的前 k 块 | ⬜ 将学 |

## B6 拼提示词回答（R6）

| 词 | 一句话 | 状态 |
| --- | --- | --- |
| 上下文注入 | 把找到的块 + 问题拼成提示词 | ⬜ 将学 |

## B7 拒答（R7）

| 词 | 一句话 | 状态 |
| --- | --- | --- |
| 阈值（threshold） | 相似度低于它就拒答（本课 0.45） | ⬜ 将学 |
| 拒答（refuse） | 老实说"不知道"，而不是瞎编 | ⬜ 将学 |

## B8 评估（R8）

| 词 | 一句话 | 状态 |
| --- | --- | --- |
| 评估集（eval set） | 一批"问题 + 期望来源"的题 | ⬜ 将学 |
| 命中率（hit rate） | top-1 / top-3 里出现期望来源的比例 | ⬜ 将学 |

# 全文记忆口诀

```
LangChain：invoke 看 content，system 定规矩；
          模板竖线 parser，tool 申请我执行；
          图点边编译，分支 ToolNode 循环；
          记忆三件套，interrupt 保平安，stream 打字机。

RAG：切块 → 向量 → 算相似 → 取 top_k → 拼提示词 → 低于阈值就拒答。
```

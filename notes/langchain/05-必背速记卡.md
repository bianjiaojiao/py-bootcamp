# 一、Python 语法（4 个必须能默写）

## 1.1 闭包 + 装饰器（写 Agent 的工具全靠它）

```python
def timer(func):
    def wrapper(*args, **kwargs):
        result = func(*args, **kwargs)    # ① 必须接住原结果
        print("干点额外的事")
        return result                      # ② 必须还回去
    return wrapper
```

**必背要点**

| 要点 | 忘了会怎样 |
|---|---|
| `return wrapper`（不带括号） | 装饰器根本没生效 |
| `*args, **kwargs` | 只能装饰无参函数 |
| **`return result`** | 被装饰的函数**返回值没了** ← 我踩过 |

## 1.2 函数当值

```python
f = double            # 不带括号 = 函数本身
f(5)                  # 带括号 = 调用
apply(double, [1,2])  # 函数能当参数传
```

> `apply` 类函数**必须遍历**：`[func(v) for v in values]`

## 1.3 三种"描述结构"的东西（最易混）

| 写法 | 运行时是什么 | 怎么取值 | 校验 |
|---|---|---|---|
| `@dataclass` | 真类，有 `__init__` | `obj.name` | ❌ |
| `class X(TypedDict)` | 普通 dict | `d["name"]` | ❌ 运行时不校验 |
| `class X(BaseModel)` | Pydantic 类 | `obj.name` | ✅ 会校验 |

```python
# TypedDict：只声明"字典有哪些键"
class Movie(TypedDict):
    title: str
    year: int
m: Movie = {"title": "x", "year": 2020}     # 用下标，不是点
```

## 1.4 Annotated（LangGraph 的门槛）

```python
from typing import Annotated, get_type_hints

UserText = Annotated[str, "用户输入"]         # 给类型贴标签
hints = get_type_hints(read, include_extras=True)   # 必须 include_extras
hints["text"].__metadata__                   # ('用户输入',)
```

**必背**：`Annotated[类型, 标签]` = 标签，**运行时不改变任何行为**。

```python
messages: Annotated[list[AnyMessage], add_messages]
#                                  ↑ 没有括号！是标签不是调用
```

## 1.5 getattr（按名字取属性，安全版）

```python
getattr(obj, "tool_calls", None)   # 有就取，没有返回 None（不报错）
hasattr(obj, "tool_calls")          # True / False
```

## 1.6 import 三件事

```python
from 包.模块 import 名字      # 只是"搬名字"，不执行业务逻辑
```

判断搬来的是什么：**类**（可 `X()` 创建）/ **函数**（可 `f()`）/ **常量**（直接用，加括号报错）。

| 词 | 一句话 |

# 四、LangGraph 必背关键词（12 个）

| 词 | 一句话 |
|---|---|
| `StateGraph(State)` | 用 State 图纸**创建**空图 |
| `TypedDict` | State 的写法：声明字典有哪些键 |
| `Annotated[list, add_messages]` | 列表用**累加**方式更新 |
| `add_node("名字", 函数)` | 加节点（字符串标签 + 函数对象） |
| `add_edge(A, B)` | 固定连线 |
| `add_conditional_edges("A", 判断函数, {映射})` | 岔路口 |
| `compile()` | 图纸 → 能跑的机器（**不编译不能用**） |
| `START` / `END` | 起点 / 终点常量（不加括号） |
| `checkpointer=MemorySaver()` | 存档器（**记忆/中断必须靠它**） |
| `{"configurable": {"thread_id": ...}}` | 会话身份证 |
| `interrupt(问题)` | 图暂停，等人回答 |
| `Command(resume="yes")` | 恢复执行并回传答案 |

# 五、6 个必背骨架（能默写才算过）

## 5.1 链

```python
prompt = ChatPromptTemplate.from_messages([("system", "人设"), ("human", "{q}")])
chain = prompt | get_llm() | StrOutputParser()
print(chain.invoke({"q": "问题"}))
```

## 5.2 工具 + 绑定

```python
@tool
def add(a: int, b: int) -> int:
    """计算两数之和。"""
    return a + b

llm = get_llm(temperature=0).bind_tools([add])
print(llm.invoke("1+2").tool_calls)     # 只发请求，不执行
```

## 5.3 结构化输出

```python
class Movie(BaseModel):
    title: str = Field(description="片名")

structured = get_llm().with_structured_output(Movie, method="function_calling")
print(structured.invoke("《流浪地球》2019").title)
```

## 5.4 最小图

```python
class State(TypedDict):
    messages: Annotated[list[AnyMessage], add_messages]

def agent(state): return {"messages": [get_llm().invoke(state["messages"])]}

g = StateGraph(State)
g.add_node("agent", agent)
g.add_edge(START, "agent")
g.add_edge("agent", END)
app = g.compile()
app.invoke({"messages": [HumanMessage("你好")]})
```

## 5.5 工具循环图（Agent 核心）

```python
def should_continue(state):
    if getattr(state["messages"][-1], "tool_calls", None):
        return "tools"
    return END

g.add_node("agent", agent)
g.add_node("tools", ToolNode(TOOLS))
g.add_edge(START, "agent")
g.add_conditional_edges("agent", should_continue, {"tools": "tools", END: END})
g.add_edge("tools", "agent")     # ← 循环的关键
app = g.compile()
```

## 5.6 记忆 + 人工确认

```python
app = g.compile(checkpointer=MemorySaver())          # 必须
config = {"configurable": {"thread_id": "user-A"}}   # 会话

# 记忆
app.invoke({"messages": [("user", "我叫小明")]}, config)
app.invoke({"messages": [("user", "我叫什么")]}, config)   # 记得

# 人工确认（两次调用）
def risky(state):
    answer = interrupt("确认删除？")
    return {"ok": answer == "yes"}

app.invoke({...}, config)                    # 第 1 次：暂停，返回 __interrupt__
app.invoke(Command(resume="yes"), config)    # 第 2 次：恢复跑完
```

# 六、10 条"一句话真理"（最该记的）

1. **模型返回的是消息对象，不是字符串** → 文字要 `.content`
2. **模型不执行工具** → 它只发 `tool_calls`，执行靠 `ToolNode`（你的代码）
3. **`add_messages` 是标签不是调用** → 写在 `Annotated` 里不带括号
4. **没 checkpointer 就没记忆、也不能中断** → 暂停后没地方存状态
5. **`compile()` 之后才能 `invoke()`**
6. **`Annotated` / `TypedDict` 运行时都不校验** → 能跑通 ≠ 写对了
7. **装饰器必须 `return result`** → 否则原函数返回值丢失
8. **`apply(func, values)` 要遍历** → 不是把整个列表传给 func
9. **DeepSeek 的结构化输出必须 `method="function_calling"`**
10. **读陌生代码从下往上**（执行入口在最后几行）

# 七、错误 → 原因 速查（我踩过的）

| 报错 / 现象 | 原因 |
|---|---|
| `ModuleNotFoundError: config` | 脚本不在 agent-lab 根目录 → 加 3 行 `sys.path.insert` |
| `This response_format type is unavailable` | DeepSeek 不支持 `json_schema` → 改 `function_calling` |
| `KeyError: 'messages'` | 查了没跑过的空线程 → `(state.values or {}).get(...)` |
| 输出是 `content='…'` 一大坨 | 忘了末尾加 `StrOutputParser()` |
| 多轮对话记不住 | 要么没 checkpointer，要么没 thread_id，要么 State 少 `Annotated[..., add_messages]` |
| 图报递归超限 | 条件边没返回 `END` → 死循环 |
| 装饰后函数返回值变 `None` | 装饰器忘了 `return result` |
| PowerShell 报"无法加载模块" | 当前目录程序要加 `.\` 前缀 |
| `NameError: name 'field'` | 少 `from dataclasses import field` |
| 工具执行结果丢失 | 忘了 `tool_call_id`（用 `ToolNode` 可避免） |

# LangChain 核心词速记（17 个 · 5 组）

> **背诵版**。想查细节去 [29-LangChain基础关键词](../topics/29-LangChain基础关键词.md)。
> 这份只回答一个问题：**我该记住哪些、怎么记？**

---

## 记忆口诀（先背这 5 句）

```
调用 invoke 看 content，system 定规矩
模板 {} 加竖线，parser 变文字
tool 申请、我执行，结果 ToolMessage
图 = 点 + 边 + 编译
高级：分支、ToolNode、记忆、interrupt
```

---

## 第 1 组 · 调用（3 个）

| 词 | 一句话 |
| --- | --- |
| `invoke(x)` | 跑一次（问一次） |
| `.content` | 消息里的**文字** |
| `SystemMessage` / `HumanMessage` | **定规矩** / **我提问** |

```python
r = llm.invoke([SystemMessage("你是诗人"), HumanMessage("写一句关于月亮的")])
print(r.content)
```

> **坑**：`invoke` 返回的不是字符串，是消息对象。文字要 `.content` 取。

---

## 第 2 组 · 拼装（3 个）

| 词 | 一句话 |
| --- | --- |
| `ChatPromptTemplate` + `{}` | 带**空位**的提示词 |
| `\|` | 左边结果**喂给**右边 |
| `StrOutputParser()` | 消息 → **纯文字** |

```python
prompt = ChatPromptTemplate.from_messages([("human", "{q}")])
chain = prompt | get_llm() | StrOutputParser()
print(chain.invoke({"q": "你好"}))
```

> **坑**：用了 `StrOutputParser` 就不用再写 `.content`。

---

## 第 3 组 · 工具（3 个）

| 词 | 一句话 |
| --- | --- |
| `@tool` | 把函数变成**工具**（必须 docstring + 类型注解） |
| `bind_tools([...])` | 告诉模型"你有这些工具"（**不执行**） |
| `tool_calls` | 模型交的**申请单**（列表套字典） |

```python
@tool
def add(a: int, b: int) -> int:
    """算两个数之和"""
    return a + b

llm = get_llm().bind_tools([add])
r = llm.invoke("算 1 加 2")
print(r.tool_calls)     # [{'name':'add', 'args':{'a':1,'b':2}, 'id':'...'}]
```

**执行永远是你的活**：

```python
call = r.tool_calls[0]
result = add.invoke(call["args"])       # → 3
```

> **坑**：加了 `@tool` 之后，`add(1,2)` 会报错，必须 `add.invoke({"a":1,"b":2})`。

## 第 4 组 · 图（4 个）

| 词 | 一句话 |
| --- | --- |
| `StateGraph(State)` | 建一张图 |
| `add_node("名", 函数)` | 加**节点**（干活的） |
| `add_edge(A, B)` | 加**边**（A 之后走 B） |
| `compile()` | **编译**才能跑 |

```python
g = StateGraph(State)
g.add_node("a", 函数)
g.add_edge(START, "a")
g.add_edge("a", END)
app = g.compile()
app.invoke({"text": "hi"})
```

> **坑**：节点**只返回要改的字段**（`return {"text": ...}`），不是整个 state。

## 第 5 组 · 高级（4 个）

| 词 | 一句话 |
| --- | --- |
| `add_conditional_edges` | **岔路口**（判断函数返回节点名） |
| `ToolNode([...])` + 一条回边 | **自动**执行工具 + **循环** |
| `add_messages` + `checkpointer` + `thread_id` | **记忆三件套** |
| `interrupt` / `Command(resume=)` | **暂停**等人确认 |

```python
# 分支
g.add_conditional_edges(START, decide, {"a": "a", "b": "b"})

# 工具自动循环
g.add_node("tools", ToolNode([add]))
g.add_edge("tools", "agent")            # ← 这条就是循环

# 记忆
class State(TypedDict):
    messages: Annotated[list, add_messages]
app = g.compile(checkpointer=MemorySaver())

# 确认
answer = interrupt("确认删除吗？")
app.invoke(Command(resume="yes"), config)
```

## 一句话串起来

```
invoke 调用 → system 定规矩 → 模板填空 → 竖线串起来
→ 给工具 → 模型交申请单 → 我执行 → 结果发回去
→ 画成图 → 加分支 → 自动调工具 → 记忆 → 危险操作前问一句 → 流式输出
```

**这就是一个完整 Agent 的全过程。**

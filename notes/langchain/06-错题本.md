## 一、DeepSeek 兼容性

### 1.1 结构化输出报 `This response_format type is unavailable now`

**现象**
```python
structured = llm.with_structured_output(Movie)      # ❌ 报错
```

**原因**：新版 langchain 默认发 `response_format: json_schema`，而 **DeepSeek 只支持 `json_object`**。

**正确写法**
```python
structured = llm.with_structured_output(Movie, method="function_calling")
```

| method | DeepSeek 支持 |
| --- | --- |
| `json_schema`（默认） | ❌ |
| `json_mode` | ✅（要自己提示输出 JSON） |
| `function_calling` | ✅ **推荐** |

**教训**：「OpenAI 兼容」≠「100% 兼容」。报错先看它**具体**说不支持哪一项。

### 1.2 DeepSeek 没有 embedding 接口

RAG 的"向量化"不能找 DeepSeek。替代方案：

| 方案 | 说明 |
| --- | --- |
| **fastembed + `BAAI/bge-small-zh-v1.5`** | ✅ 采用。ONNX 实现，**不用装 2.5GB torch** |
| Ollama 本地 embedding | 需装 Ollama |
| 其他厂商 embedding API | 要另一把 key |

## 二、环境与路径

### 2.1 PowerShell 里跑当前目录程序要加 `.\`

| 窗口 | 写法 |
| --- | --- |
| cmd（`C:\...>`） | `.venv\Scripts\python.exe 01.py` |
| **PowerShell**（`PS C:\...>`） | `.\.venv\Scripts\python.exe 01.py` |

### 2.2 子目录脚本 `from config import ...` 报 ModuleNotFoundError

**原因**：Python 的搜索路径从"脚本所在目录"开始，子目录里的脚本找不到上层的 `config.py`。

**解决**：文件开头加三行
```python
import sys
from pathlib import Path

sys.path.insert(0, str(Path(__file__).resolve().parent.parent))
```

### 2.3 IDE 自动导入塞垃圾 import（发生过 2 次）

```python
from curses import wrapper      # 打了 wrapper 后 PyCharm 自动补的
from pygame import key          # 打了 key 后自动补的
```

**解决**：Settings → Editor → General → Auto Import → 取消勾选 `Add unambiguous imports on the fly` 和 `Show import popup`。

**判断标准**：**提示让你少打字 → 可以；替你决策 → 不行。**

## 三、LangChain / LangGraph 运行时

### 3.1 `StrOutputParser` 返回的类型不是 `str`

新版返回 `TextAccessor`（str 的子类）。判断用 `isinstance(out, str)`（结果为 True），别用 `type(out) is str`。

### 3.2 空会话查状态报 `KeyError: 'messages'`

```python
state = app.get_state(config)          # 从没跑过的 thread → values 是空字典
len(state.values["messages"])          # ❌ KeyError
```

**正确**
```python
messages = (state.values or {}).get("messages", [])
```

### 3.3 多轮对话记不住 / interrupt 无法恢复

三件套缺一不可：

| 缺什么 | 后果 |
| --- | --- |
| `Annotated[list, add_messages]` | 新消息覆盖历史 |
| `compile(checkpointer=...)` | 没地方存状态 → 记忆和中断都失效 |
| `thread_id` | 所有会话共用一个记忆 |

## 四、RAG 调优

### 4.1 明明笔记里有，却答"没有相关内容"

**排查链**（真实案例：问 `frozen=True` 却检索不到）

| 步骤 | 发现 |
| --- | --- |
| ① 查排名 | 讲 `frozen` 的片段排第 **24 / 39 / 96** 名 |
| ② 切分 400→200 | 没用，分数挤在 0.65~0.70（细节被"平均"掉） |
| ③ **片段加《标题》前缀** | **冲进 top-3** ✅ |
| ④ top_k 3→6 | 更稳 |

**结论**：向量检索只是"粗排"。提升精确命中靠：**加标题前缀 / 混合检索（关键词+向量）/ rerank 模型**。

### 4.2 阈值必须设

实测：相关问题最高分 0.65~0.72，无关问题 0.28~0.36 → 阈值取 **0.45** 能干净分开。
低于阈值就答"没有相关内容"，这是防幻觉最有效的一招。

### 4.3 国内下模型要设镜像

```powershell
$env:HF_ENDPOINT = "https://hf-mirror.com"
```

## 五、Git

### 5.1 `.env.*` 会误伤 `.env.example`

`.gitignore` 里写 `.env.*` 会把模板文件也排除 → 加白名单：

```gitignore
.env
.env.*
!.env.example
```

### 5.2 提交前必须确认密钥没进去

```bash
git check-ignore -v .env      # 应该输出匹配的规则
```

### 语法类（冒号 / 拼写 / 缩进）

| # | 我写的 | 正确 | 为什么 |
|---|---|---|---|
| 1 | `def make_multiplier(n)` | `def make_multiplier(n):` | `def` / `if` / `for` / `class` **后面永远有冒号** |
| 2 | `class Movie(TypeDict):` | `class Movie(TypedDict):` | 拼写错：Typed**Dict** |
| 3 | `class Movie(TypeDict)` | `class Movie(TypedDict):` | 又是缺冒号 |
| 4 | `def read(text)->str` | `def read(text: UserText) -> str:` | 缺冒号 |
| 5 | `def summarize(items:list[int])` | `def summarize(items: list[int]):` | 缺冒号 |
| 6 | Tab 缩进 + 4 空格混用 | 全部用 **4 个空格** | Python 不允许同一代码块混用缩进方式 |
| 7 | `from curses import wrapper`（IDE 自动导入） | 删掉 | PyCharm 自动补的垃圾导入，永远不要接受你不认识的 import |
| 8 | `from pygame import key`（上次同类错误） | 删掉 | 同上 |

### 概念类（这才是重点）

| # | 我的错 | 正确 | 知识点 |
|---|---|---|---|
| 9 | `for i in nums: nums[i] *= 2` | `for x in nums: ...` 或用 `enumerate` | **`for i in 列表` 里的 i 是"元素值"，不是下标！** 用值当下标会 IndexError |
| 10 | `def safe_get(user, name)` 但断言传 3 个参数 | `def safe_get(user, attr, default)` | **写函数前先看它怎么被调用**（看 assert 那行），倒推参数个数 |
| 11 | `getattr(user, name)` | `getattr(user, name, default)` | 不给默认值，属性不存在时会 `AttributeError` |
| 12 | `class Movie(TypedDict)` 然后 `m = Movie()` | `m: Movie = {"title": ..., "year": ...}` | **TypedDict 不能用 `()` 实例化**——运行时它就是普通字典 |
| 13 | `@dataclass` 里 `score:list[int].field(...)` | `scores: list[int] = field(default_factory=list)` | 是**赋值 `=`**，不是点号 `.`；字段名要跟断言一致（`scores`） |
| 14 | `def read(...): return UserText` | `return text` | 返回的是**参数**，不是类型对象 `UserText` |
| 15 | `def __init__: count = 0` | `def __init__(self): self.count = 0` | ① 方法第一个参数永远是 `self` ② 要存到对象上必须写 `self.xxx` |
| 16 | `def add(count): return count+1` | `def add(self): self.count += 1` | 要**修改对象属性**，不是返回新值 |
| 17 | `if list == []:` / `for i in list:` | `if items == []:` / `for i in items:` | 参数名是 `items`，不是 `list`（`list` 是内置函数名，别覆盖） |
| 18 | `len(list[])` | `len(items)` | `list[]` 是语法错误（空下标） |
| 19 | 装饰器 `return wrapper()` | `return wrapper` | 返回**函数本身**，加括号就变成"立刻调用"了 |
| 20 | 装饰器 `return result` | `return f"[{result}]"` | 装饰器要"加工"原结果，不是原样返回 |
| 21 | `def greet(...) -> str` 但返回 None | `-> None` | 注解要如实描述返回值 |

## 高频错误 Top 3（要重点盯）

1. **缺冒号**（5 次）→ `def` / `class` / `if` / `for` 后面永远有冒号
2. **参数个数对不上**（3 次）→ 写函数前先看"它怎么被调用"
3. **`self` 用错**（3 次）→ 方法第一参数是 `self`；存属性必须 `self.xxx = ...`

## IDE 自动导入黑名单（见到就删）

| 出现过的垃圾导入 | 原因 |
|---|---|
| `from curses import wrapper` | 打了 `wrapper` |
| `from pygame import key` | 打了 `key` |

> **PyCharm 设置**：Settings → Editor → General → Auto Import → 取消 "Add unambiguous imports on the fly"
> 或者看到导入提示框就按 `Esc` 关掉。

## 一、循环与迭代

### 1.1 `for x in 列表` 里的 x 是**元素**，不是下标

**我写的**（drills/01 第 3 关）
```python
def double(nums):
    for i in nums:          # i 是 1、2、3（元素值）
        nums[i] *= 2        # 拿值当下标 → nums[3] 越界
```

**为什么错**：`for x in 可迭代对象` 直接给你**元素**。要下标必须用 `range(len())` 或 `enumerate()`。

**正确写法**
```python
for x in nums:                    # 只要值
for i in range(len(nums)):        # 只要下标
for i, x in enumerate(nums):      # 两个都要（最常用）
```

**口诀**：**`for` 拿值，`enumerate` 拿"下标+值"。**

### 1.2 `while` 和 `if` 别混

**我写的**（drills/02 第 3 关）
```python
def withdraw(self, amount):
    while self.balance - amount >= 0:   # 只要满足就反复扣！
        self.balance -= amount
```

**为什么错**：`while` 是"条件成立就一直做"；这里只需要**判断一次**。

| 需求 | 用哪个 |
| --- | --- |
| 判断一次，然后走一条分支 | `if` |
| 重复做直到条件不成立 | `while` |
| 遍历一个集合 | `for` |

## 二、函数：参数与返回

### 2.1 参数个数要和"怎么被调用"一致

**我写的**（drills/01 第 5 关）
```python
def safe_get(user, name):                     # 只收 2 个
    return getattr(user, name)
# 但调用是 safe_get(User(), "age", "未知")    ← 传了 3 个
```

**报错**：`TypeError: safe_get() takes 2 positional arguments but 3 were given`

**正确做法**：**写函数前先看它怎么被调用**（看 assert 那行），倒推参数。

```python
def safe_get(user, attr, default):
    return getattr(user, attr, default)
```

**口诀**：**先看调用，再写定义。**

### 2.2 `+=` 是**语句**，不能出现在 `return` 里

**我写的**（drills/02 第 3 关）
```python
return self.balance += amount      # SyntaxError
```

**为什么错**：Python 代码分两类——

| 类别 | 例子 | 能 `return` 吗 |
| --- | --- | --- |
| **语句** statement | `x += 1`、`if`、`for`、`return` | ❌ |
| **表达式** expression | `x + 1`、`f()`、`a if b else c` | ✅ |

**正确写法**
```python
self.balance += amount             # 语句独立一行（不改返回值）
# 或者
return self.balance + amount       # 表达式（但同时不修改属性）
```

### 2.3 返回「参数」而不是「类型对象」

**我写的**（drills/01 第 10 关）
```python
UserText = Annotated[str, "用户输入"]

def read(text: UserText) -> str:
    return UserText          # ❌ 返回的是"类型"，不是传进来的值
```

**正确写法**：`return text`

**口诀**：**注解是写给别人的说明书，函数体里只认真实的参数名。**

## 三、对象与 self

### 3.1 存到对象上必须 `self.xxx = ...`

**我写的**（drills/01 第 11 关）
```python
class Counter:
    def __init__:            # 缺 self
        count = 0            # 这是局部变量，对象身上没有
    def add(count):          # 缺 self
        return count + 1     # 返回值也没人用
```

**正确写法**
```python
class Counter:
    def __init__(self):
        self.count = 0       # 存到对象上
    def add(self):
        self.count += 1      # 改对象上的值
```

**三条硬规矩**：
1. 方法第一个参数永远是 `self`
2. 想"记住"东西 → `self.xxx = 值`
3. 想"改"状态 → `self.xxx += 1`（不是 return 新值）

### 3.2 `self` 是"这个对象自己"，不是类

```python
a = BankAccount("小明")
a.deposit(100)      # 此时 self 就是 a
b = BankAccount("小红")
b.deposit(50)       # 此时 self 就是 b
```

**口诀**：**`self` = 调用这个方法的那一个对象。**

## 四、属性访问与下标

### 4.1 属性用 `.`，字典用 `[""]`（跟类型走）

| 类型 | 怎么创建 | 怎么取值 |
| --- | --- | --- |
| `@dataclass` | `Student("小明", 20)` | `s.name` ← **点** |
| `TypedDict` | `{"name": "小明"}` | `d["name"]` ← **下标** |
| 普通 dict | `{"a": 1}` | `d["a"]` 或 `d.get("a", 0)` |

**我犯过错**：`score:list[int].field(...)` —— 把「赋值」写成了「属性访问」。正确的是 `scores: list[int] = field(...)`。

### 4.2 `list.index()` 找不到会**抛异常**，不是返回 -1

**我写的**（drills/02 第 1 关）
```python
def index_of(nums, target):
    return nums.index(target)     # 找不到 → ValueError，直接崩
```

**容易混的点**：

| 方法 | 找不到时 |
| --- | --- |
| `str.find("x")` | 返回 `-1` |
| `list.index(x)` | **抛 `ValueError`** |

**正确写法**（要返回 -1 就得自己写循环）
```python
def index_of(nums, target):
    for i, x in enumerate(nums):
        if x == target:
            return i
    return -1
```

## 五、类型与数据结构选择

### 5.1 TypedDict **不能**用 `()` 实例化（我犯过 **2 次**）

**我写的**（drills/01 第 8 关 & drills/02 第 6 关，同一个坑）
```python
class Config(TypedDict):
    model: str
cfg = Config("deepseek-chat", 0)      # ❌ TypedDict 不能被调用
```

**为什么错**：TypedDict **运行时就是普通字典**，它只负责"告诉编辑器和读者：这个字典有哪些键"。它没有构造函数。

**正确写法**
```python
cfg: Config = {"model": "deepseek-chat", "temperature": 0.0}
```

**口诀**：**dataclass 用括号造对象，TypedDict 用花括号写字典。**

### 5.2 三个"描述结构"的东西怎么选

| 用什么 | 场景 |
| --- | --- |
| `@dataclass` | 自己要造对象，需要 `.属性` 访问、默认值、比较 |
| `TypedDict` | 描述"别人给我的字典"长什么样（运行时仍是 dict） |
| `BaseModel`（Pydantic） | 需要**运行时校验**（数据来自外部/HTTP/JSON） |

### 5.3 类型注解要如实描述

**我写的**：`def greet(name: str) -> str:` 但函数里 `return None`
→ 应该是 `-> None`

**口诀**：**注解是承诺，返回什么就写什么。**

## 六、装饰器

### 6.1 最后要 `return wrapper`（不加括号！）

**我写的**（drills/01 第 7 关）
```python
def add_tag(func):
    def wrapper(...):
        ...
    return wrapper()      # ❌ 这是"立刻调用"，返回的是结果
```

| 写法 | 含义 |
| --- | --- |
| `return wrapper` | 返回**函数本身** → 装饰成功 ✅ |
| `return wrapper()` | 立刻调用了一次，返回它的结果 → 装饰失败 ❌ |

### 6.2 要"加工"原结果，不是原样返回

**我写的**
```python
def wrapper():
    result = func()
    return result              # ❌ 什么都没加，等于没装饰
```

**正确**
```python
def wrapper():
    result = func()
    return f"[{result}]"       # ✅ 加工后再返回
```

**五步骨架（背下来）**
```python
def 装饰器(func):                    # ① 收函数
    def wrapper(*args, **kwargs):    # ② 内层函数
        result = func(*args, **kwargs)   # ③ 调用原函数
        return 加工(result)              # ④ 加工后返回
    return wrapper                   # ⑤ 返回函数本身（不调用）
```

## 七、命名与内置名

### 7.1 别用 `dict` / `list` / `sum` / `max` / `str` 当变量名

**我写的**（drills/01 第 12 关 & drills/02 第 8 关）
```python
def count_words(text):
    if text in dict:        # dict 是内置类型！
        return dict[text] = 0
    for i in list:          # list 也是内置类型！
```

**为什么危险**：这些名字本来是 Python 内置的**类/函数**，你覆盖之后，后面所有 `dict()`、`list()`、`sum()` 都会坏掉。

**正确做法**：用有意义的名字
```python
result = {}
items = []
total = sum(nums)
```

### 7.2 参数名要用题目给的那个

题目参数叫 `items`，就要用 `items`；不能换成 `list` 或 `nums`（除非你自己能保持一致）。

## 八、累加与分组套路

### 8.1 计数：`d[k] = d.get(k, 0) + 1`

**我写的**（drills/02 第 8 关）：没有建容器、没有遍历、`return` 里塞赋值。

**标准写法**
```python
def count_words(text: str) -> dict[str, int]:
    result = {}                            # ① 先建空容器
    for w in text.split():                 # ② 切分后遍历
        result[w] = result.get(w, 0) + 1   # ③ 有就 +1，没有从 0 开始
    return result
```

**这个套路你会反复遇到**：词频统计、计分、统计工具调用次数、统计每个用户的请求数……

### 8.2 字典里存列表：先占位，再追加

**我卡住的**（drills/02 第 10 关）：不知道"字典的值是列表"怎么写。

**方法 A：`setdefault`（最简洁）**
```python
result.setdefault(w[0], []).append(w)
```

`setdefault(k, 默认值)` 的行为：

| 情况 | 返回 | 副作用 |
| --- | --- | --- |
| k 不存在 | 默认值 `[]` | **同时把 k 设成这个默认值** |
| k 已存在 | 现有的列表 | 不改动 |

**方法 B：先判断再占位（更好懂）**
```python
key = w[0]
if key not in result:
    result[key] = []        # 先占位
result[key].append(w)       # 再追加
```

**口诀**：**"字典 + 列表" = 先占位，再 append。**

## 九、逻辑与测试思维（新）

### 9.1 状态变了以后，别再用旧条件判断

**我写的**（drills/02 第 3 关，测试居然过了）
```python
def withdraw(self, amount):
    if self.balance - amount >= 0:          # ① 判断
        self.balance -= amount              # ② 钱扣了，balance 变了
        return self.balance - amount >= 0   # ③ 用【新的】balance 再判断一次
```

**实际后果**（余额 100）

| 操作 | 返回 | 余额 | 对不对 |
| --- | --- | --- | --- |
| 取 30 | True | 70 | 碰巧对 |
| 取 60 | **False** | **40（钱扣了）** | ❌ 扣了钱却说失败 |
| 取 70 | **False** | **30（钱扣了）** | ❌ 同上 |
| 取 1000 | False | 100 | 对（走 else） |

**正确写法**：判断一次就够
```python
def withdraw(self, amount):
    if amount <= self.balance:
        self.balance -= amount
        return True
    return False
```

**口诀**：**先判断再改状态；改完别回头用旧条件。**

### 9.2 测试通过 ≠ 代码正确

上面那个 bug 藏了很久，因为**我写的测试用例刚好绕过了它**（取 30 碰巧对、取 1000 走 else）。

**教训**：
- 测试只覆盖"你想到的情况"
- 边界值要专门测：**刚好够 / 差一点 / 刚好超一点**
- 代码能跑绿，还要**自己读一遍逻辑**

### 9.3 列表"拼接" vs "追加"

**我写的**
```python
result[key] = result.get(key, []) + [w]     # 每次都复制整个旧列表
```

**更好的写法**
```python
result.setdefault(key, []).append(w)        # 原地追加，一个列表只建一次
```

| 写法 | 复杂度 | 说明 |
| --- | --- | --- |
| `old + [x]` | 每次复制 O(n) → 累积 O(n²) | 数据少时没感觉 |
| `list.append(x)` | O(1) | 标准做法 |

**口诀**：**往列表里加东西用 `append`，不要用 `+`。**

## 十、线程与闭包（17/18 重点补记）

> 这两章是 10-18 学的，隔了 12 天全忘了。**忘不是问题，API 细节需要捡回来** —— 下面是要点卡片。

### 10.1 线程三件套（必须背）

```python
import threading

t = threading.Thread(target=函数, args=(参数,), kwargs={"k": v})
t.start()      # 开跑
t.join()       # 主线程等它结束
```

**三个"不"**

| 规则 | 错了会怎样 |
| --- | --- |
| `target` **不加括号** | 加了括号 = 立刻执行，线程变空转 |
| 一个 Thread 对象**只 start 一次** | 第二次 `RuntimeError: threads can only be started once` |
| **先全部 start，再全部 join** | 挤在一个循环里 = 串行，没有并发 |

**正确范式**

```python
threads = [threading.Thread(target=add_10k) for _ in range(4)]
for t in threads: t.start()
for t in threads: t.join()
```

### 10.2 Lock（保护共享变量）

```python
counter = 0
lock = threading.Lock()

def add_10k():
    global counter              # ① 改全局变量必须声明
    for _ in range(10000):
        with lock:              # ② 锁住"读-改-写"三步
            counter += 1
```

| 要点 | 说明 |
| --- | --- |
| 为什么要锁 | `counter += 1` 是"读→改→写"，多线程交错会丢更新（**竞态条件**） |
| `with lock:` | 进 with 拿锁，出 with 自动放锁 |
| `global counter` | 不写就是新建局部变量，全局那个不变 |

**验证**：4 线程 × 10000 = **40000**（去掉 `with lock` 通常会小于 40000）

### 10.3 Condition（生产者-消费者）

```python
cond = threading.Condition()
items = []

def producer():
    with cond:
        items.append(1)
        cond.notify()          # 叫醒一个等待者

def consumer():
    with cond:
        while not items:       # 用 while 防虚假唤醒
            cond.wait()        # 释放锁 + 等待
        items.pop()
```

| 方法 | 作用 |
| --- | --- |
| `cond.wait()` | 释放锁并等待，直到被 notify |
| `cond.notify()` | 唤醒 1 个等待者 |
| `cond.notify_all()` | 唤醒全部 |

### 10.4 闭包 + `nonlocal`

```python
def make_counter():
    count = 0
    def inner():
        nonlocal count       # ← 修改外层变量必须声明
        count += 1
        return count
    return inner             # ← 返回函数本身，不加括号

c1 = make_counter()
c2 = make_counter()
print(c1(), c1(), c2())      # 1 2 1   ← 互不干扰
```

| 你想做的事 | 要 `nonlocal` 吗 |
| --- | --- |
| 只**读**外层变量 | ❌ 不用 |
| **修改**（`+=`、赋值） | ✅ 必须，否则 `UnboundLocalError` |

**为什么两个计数器互不干扰**：每次调用 `make_counter()` 都新建一个 `count`，各自绑各自的"背包"。

### 10.5 计时装饰器（五步骨架 + 一个易错点）

```python
import time

def insert_time(func):              # ① 收函数
    def wrapper(*args, **kwargs):   # ② 内层（是 **kwargs，不是 *kwargs）
        start = time.time()
        result = func(*args, **kwargs)   # ③ 调用原函数
        print(f"耗时 {time.time() - start:.2f} 秒")
        return result               # ④ 还回去
    return wrapper                  # ⑤ 返回函数本身（不加括号）

@insert_time
def slow():
    time.sleep(0.5)

slow()      # 这样才会打印耗时
```

## 十一、⚠️ 重复犯了 2 次的坑：函数当值，不加括号

**同一个概念，在不同场景翻车两次**：

| # | 场景 | 我的写法 | 为什么错 |
| --- | --- | --- | --- |
| 1 | drills 第 1 关 | `apply(double, [1,2,3])` | ✅ 这里写**对了**（传函数名） |
| 2 | 17.py 线程 | `Thread(target=add_100())` | ❌ 立刻执行了，`target` 变成 `None` |
| 3 | 18.1.py 装饰器 | `insert_time(a())` | ❌ 先执行 `a()`，把返回值传给装饰器，**装饰器根本没生效** |

**根子上的区别**

| 写法 | 含义 |
| --- | --- |
| `函数名` | 函数**本身**（一个值，可以传给别人） |
| `函数名()` | **调用**它，得到结果 |

**正确写法**

```python
Thread(target=add_100)          # 传函数本身 ✅
insert_time(a)                  # 传函数本身 ✅

@insert_time                    # 装饰器语法，等价于 a = insert_time(a)
def a(): ...
```

**口诀**：**"传给别人以后再说"→ 不加括号；"现在就执行"→ 加括号。**

> 这个坑难查的原因：`insert_time(a())` 语法完全合法，Python 不报错，只是**默默做了错事**。
> 所以每次看到"把函数当参数传"，先数一下有没有括号。

## 十二、`break` 只能在循环里

```python
if y == 0:
    break            # ❌ SyntaxError: 'break' outside loop
```

| 语句 | 只能在 |
| --- | --- |
| `break` / `continue` | **循环**（`for` / `while`）里面 |
| `return` | **函数**里面 |

想"提前跳出函数"用 `return`；想"跳出循环"才用 `break`。

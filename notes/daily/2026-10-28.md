## 📚 今日知识点

| 主题 | 一句话要点 |
| --- | --- |
| 工程化第一步 | **把脚本拆成模块**：一个文件只干一件事，主流程只做编排 |
| 索引缓存 | 向量化很贵，结果存磁盘（`.npz`），下次直接 load |
| `.gitignore` 白名单 | `.env.*` 会连 `.env.example` 一起忽略，要用 `!.env.example` 反选回来 |
| 项目 vs 脚本 | 脚本求"跑通"; 项目求"别人能装、能跑、能改"（README + requirements + .env.example） |

## ⚠️ 今日易错点

1. `.gitignore` 写 `.env.*` 会误伤模板文件，必须加 `!.env.example`
2. 索引缓存文件不要提交（体积 + 每个人的笔记不同）→ `data/` 进 gitignore
3. `pip install sentence-transformers` 会拖 2.5GB torch → 用 `fastembed`（ONNX）
4. 国内下模型记得设 `HF_ENDPOINT=https://hf-mirror.com`

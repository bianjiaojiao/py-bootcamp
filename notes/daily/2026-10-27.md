**从数字里学到的 3 件事**：

1. **相似度阈值**：0.6+ 相关 / 0.3 左右无关 → 生产系统设阈值，低于就答"没有相关资料"
2. **必须取 top-k 而不是 top-1**：dataclass 那题第 1 名错了，第 2 名才对，取前 3 条一起喂模型就能兜住
3. **RAG 的全部秘密**：问题 → 向量 → 和所有片段比相似度 → 取最像的几段 → 拼进提示词

**排错实录（今天最值钱的经验）**

| 步骤 | 现象 | 诊断 |
| --- | --- | --- |
| ① 初版 | 第 3 题答"没有相关内容"，但其实笔记里有 | 检索没命中真正讲 `frozen` 的片段 |
| ② 查排名 | 含 `frozen` 的 5 个片段排在第 **24 / 39 / 96** 名 | 向量检索是**粗排**，不保证精确命中细节 |
| ③ 调小 chunk（400→200） | 没有改善，分数全挤在 0.65~0.70 | 小模型分辨不出"概览"和"细节"，相邻主题互相打架 |
| ④ **给片段加标题**（`《23-dataclass》` 前缀） | **frozen 片段冲进 top-3** | 片段自带主题标签后，主题归属清楚了 |
| ⑤ 定稿：chunk 200 + 标题前缀 + k=6 | 四题全对 | ✅ |

**学到的规律**：

1. **RAG 出问题，先怀疑检索，别怀疑模型**
2. 向量检索只能"粗排"，真正精确命中要靠：**加标题前缀 / 混合检索（关键词+向量）/ rerank 模型**
3. **top-k 要够大**（3 太小，6 才稳），因为好片段经常排在第 3~6 名
4. **必须设相似度阈值**（0.45）：低于就答"没有资料"，这才是诚实，也避免幻觉

## 📚 今日知识点

| 主题 | 一句话要点 |
| --- | --- |
| 记忆三件套 | 累加（`Annotated`）+ 存档（`checkpointer`）+ 会话（`thread_id`），缺一不可 |
| interrupt 机制 | **两次调用**：第一次跑到 `interrupt()` 暂停返回 `__interrupt__`；第二次 `Command(resume=值)` 从暂停处继续。**必须靠 checkpointer 存中间状态** |
| 流式两种 | `llm.stream()` 逐字吐（体验）；`app.stream(stream_mode="updates"/"values")` 看每步（调试） |
| embedding | 把文字变成一串数字（向量），语义相近的向量"距离"近 |
| 余弦相似度 | 算两个向量"像不像"，范围 -1~1，越大越像 |
| chunk（切分） | 模型一次看不了太长，所以要切成小段，每段单独向量化 |

## ⚠️ 今日易错点

1. `interrupt` 少了 `checkpointer` → 暂停后无法恢复（中间状态没地方存）
2. `Command(resume=...)` 是**第二次调用**用的，不是第一次
3. `app.get_state(config).next` 可以看"图停在哪一步"
4. 只取 top-1 做 RAG → 检索错一次就全错，必须 top-k（3~5）
5. 忘记设相似度阈值 → 无关问题也会硬凑一段资料给模型

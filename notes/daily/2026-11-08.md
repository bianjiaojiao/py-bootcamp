## 二、补了异步（之前完全没学过）

实验数据：

```
同步：3 个任务各等 1 秒 → 3.0 秒
异步：3 个任务一起等   → 1.0 秒
```

**核心一句话：`await` = 我等着，但把 CPU 让给别人。**

| 铁律 | 说明 |
| --- | --- |
| `async def` 直接调用**不执行** | 必须 `asyncio.run(...)` |
| `async` 里用 `time.sleep()` = 白写 | 要用 `asyncio.sleep()` |
| `await` 只能写在 `async def` 里 | 否则语法错误 |
| **CPU 密集别用异步** | 用多进程；异步只省"等待" |

详见：[32-asyncio异步编程](../topics/32-asyncio异步编程.md)

## 四、今天最重要的认知：**语法 ≠ 库 API**

我问了一个问题："这些方法是基础语法吗？"

答案是**不是**。界线很清楚：

| 类别 | 例子 | 要不要背 |
| --- | --- | --- |
| **语言语法** | `if` / `for` / `class` / `with` / `try` / `lambda` / 解包 / 推导式 / `@property` / `super()` | **必须会**（不查文档） |
| **标准库 API** | `re.sub` / `heapq.nlargest` / `deque(maxlen=)` / `lru_cache` / `json.dumps` | **查文档就会**，知道名字就够 |

**判断标准**：

```
不查文档就必须会  →  语法（缺了要补）
查一下就会        →  API（知道存在就行）
```

### 语法审计结果（32 篇专题 + 2 篇新增）

| 语法 | 状态 |
| --- | --- |
| `match/case`、`try/else/finally`、`map/filter`、三元表达式、`*args/**kwargs`、`lambda`、列表/字典/集合推导 | ✅ 有 |
| **`zip`** | ❌ **真缺口**（已补，见下） |
| 海象 `:=`、`yield from`、`__slots__`、`for-else`、`globals()`、`contextlib` | ⚠️ 冷门/进阶，用到再学 |

**结论：基础语法基本齐了，只差 `zip`。**

## 五、补学：`zip`（并行遍历）

```python
names = ["小明", "小红", "小刚"]
scores = [90, 85, 77]

for name, score in zip(names, scores):
    print(name, score)

# 转字典（最常用）
d = dict(zip(names, scores))     # {"小明": 90, "小红": 85, "小刚": 77}
```

**和 `enumerate` 的区别**：

| 函数 | 给什么 |
| --- | --- |
| `enumerate(列表)` | 下标 + 元素 |
| `zip(列表1, 列表2)` | 两个列表的对应元素 |

**在哪见过**：`course-rag/rag/store.py:82` 的 `zip(data["texts"], data["sources"])`。

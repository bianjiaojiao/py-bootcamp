## 📚 今日知识点

| 主题 | 一句话要点 |

| [语法补齐专区（独立）](../langchain/README.md) | LangChain 相关内容独立存放，不与 Python 基础专题混编 |
| 装饰器常见 bug | 装饰器必须 `return result`，否则被装饰函数"返回值消失" |
| TypedDict 的本质 | 运行时**完全不校验**，只是给编辑器看的类型提示 → **能跑通 ≠ 写对了** |
| Annotated 的本质 | `Annotated[list, add_messages]` = 给 list 贴一个"累加函数"标签 |

## ⚠️ 今日易错点

1. `apply(func, values)` 要**遍历**，不是把整个列表传进去
2. 装饰器忘了 `return result` → 原函数返回值丢失
3. IDE 自动导入的垃圾 import（如 `from pygame import key`）要删掉
4. `field(default_factory=...)` 必须先 `from dataclasses import field`
5. TypedDict 写错键**不报错**，只有编辑器画红线
6. 括号不加（`read(text:UserText)->str:` 缺 `def`）→ SyntaxError

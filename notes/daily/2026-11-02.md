## 🔑 首轮考核暴露的 3 个问题（比分数更值钱）

### 1. `TOOL = []` —— 定义了三工具，一个都没装

```python
@tool
def add(a, b): ...
@tool
def reverse_text(text): ...
@tool
def count_word(text): ...

TOOL = []                          # ← 全白定义了
llm = get_llm().bind_tools(TOOL)   # ← 绑了个空列表
```

结果：模型手上没工具，`tool_calls` 是空的，它自己心算出了 42。

**教训**：**定义 ≠ 用上**。每次声明完，确认它真的被引用了。

### 2. `text.reserve()` —— 字符串没有这个方法

Python 字符串反转用**切片**：`text[::-1]`（专题 02 学过）。

**会的方法名**：`reserve` 是 C++ 的（预留容量），Python 完全没有。

### 3. `.content` 漏了，打印出 `content="..."`

```python
state["answer"] = llm.invoke(q)                 # ❌ 存了消息对象
state["answer"] = llm.invoke(q).content         # ✅ 存字符串
```

错误表现很好认：输出里出现 `content="..."` 这种字样，就是消息对象被当字符串拼进去了。

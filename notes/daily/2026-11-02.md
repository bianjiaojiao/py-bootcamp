## 三、代码风格铁律（写进课表）

> 起因：示例代码里用了 `enumerate(QUESTIONS, 1)`、元组解包、`sorted(set(...))`、`{!r}`，
> 这些**跟当课知识点无关**，反而分散注意力。

**规则**：除非本课就是在讲它，否则不许出现

| 禁止 | 替代 |
| --- | --- |
| `enumerate` / 元组解包 | 平铺写 3 段 |
| 列表推导 / 生成器表达式 | 普通 for |
| `sorted` / `set` / `functools` | 不用 |
| f-string 格式符 `{x:>6.2f}` / `{!r}` | `round(x, 3)` |
| 一行多个操作 `f(g(h(x)))` | 拆成三行 |

**执行标准**：示例代码能一眼看完，每行只干一件事。**宁可写 3 遍重复代码，也不引入没学过的语法。**

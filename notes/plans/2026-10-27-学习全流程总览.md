## 四、剩余部分（详细）

### E · RAG（⬜ 下一个）

**要学**：

```
读文档 → 切分 → 向量化(embedding) → 存向量库 → 检索 → 拼提示词 → 生成
```

| 知识点 | 说明 |
| --- | --- |
| 文档加载 | `TextLoader` / `Docx2txtLoader` / `PyPDFLoader` |
| 切分 | `RecursiveCharacterTextSplitter`（`chunk_size` / `chunk_overlap`） |
| **Embedding** | ⚠️ **DeepSeek 没有 embedding 接口** → 用本地 `BAAI/bge-small-zh-v1.5` |
| 向量库 | Chroma（本地、省事） |
| 检索 | 相似度检索、MMR、多查询 |
| 引用溯源 | 回答里标注"出自哪篇笔记" |

**产出**：`course-rag` —— 用你自己的 `notes/topics/` 做知识库，问"线程和进程怎么选"能答出来并给出处。

**门槛提示**：需要装 `sentence-transformers` + 下载模型（约 100MB），第一次会慢。

### F · 工程化与部署（⬜）

| 内容 | 关键点 |
| --- | --- |
| 配置管理 | `pydantic-settings` |
| 可观测 | LangSmith / Langfuse 看 trace |
| 服务化 | FastAPI（用 `def` 不用 `async`） |
| 部署 | Docker + 环境变量注入 |
| 测试 | pytest（**mock 掉 LLM**，别每次都真调） |

**产出**：`agent-service`（RAG 封装成 API，能 Docker 起服务）
